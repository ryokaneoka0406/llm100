# Paper Summarizer

[https://summarize-paper.com/](https://summarize-paper.com/)

## Overview

Paper Summarizer is a research support SaaS for researchers, students, and engineers. It allows you to quickly search for arXiv papers, generate AI-powered summaries, and interact with papers via Q&A. The service leverages Google Gemini for AI processing and provides a seamless workflow for paper research and understanding.

- **arXiv Search**: Instantly search for the latest papers on arXiv by keyword, author, or arXiv ID.
- **AI Summarization**: Automatically generate concise and easy-to-understand summaries of papers using AI. English papers are summarized in Japanese as well.
- **Q&A with AI**: Ask questions about the content of any paper and get instant answers from AI. For example, "What is novel about this paper?" or "What are possible applications?"
- **User-Friendly Interface**: Modern UI with dark/light mode, responsive design, and easy navigation.
- **Authentication**: Secure Google OAuth login and user management.
- **Persistent Storage**: All user data and paper interactions are securely stored.

# Paper Summarizer（日本語）

## 概要

Paper Summarizer は、研究者・学生・技術者のための論文リサーチ支援 SaaS です。arXiv の論文を素早く検索し、AI による要約を自動生成し、さらに論文内容について AI に質問できます。Google Gemini を活用した AI 処理により、論文理解とリサーチを効率化します。

- **arXiv 論文検索**：キーワード、著者名、arXiv ID で最新の論文を即座に検索可能
- **AI 要約生成**：AI が論文の要点や概要を自動で分かりやすく要約。英語論文も日本語で要約されます
- **AI による Q&A**：論文内容について自由に AI に質問可能。「この論文の新規性は？」「どんな応用が考えられる？」なども即回答
- **認証機能**：Google OAuth による安全なログインとユーザー管理
- **データ永続化**：ユーザーデータや論文のやり取りは安全に保存
